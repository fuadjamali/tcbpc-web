Limits of “no app code changes” — decisions needed

  1. Colours: the app has no Dojo teal/green theme; only its 8 built-in palettes. Mockup uses Forest Green. A true Dojo palette (#3CEAC7 / #003F33 / #180F06 / #F1F1EC) and Inter font would need a small CSS change in app/globals.css.
  2. Images: Blob storage isn’t configured locally, so the supplied .webp photos would be copied into public/images/tcbpc/ (static assets, not code) and referenced by path. Portfolio needs an image per merchant: I can generate simple branded name tiles, or you can supply logos.
  3. Not possible without code: the 3D scroll-driven hero, black/white finish toggle, tabbed hardware explorer, “Business Name” field and product-prefilled message on the quote form, ZIP/HTML download buttons. Replaced by the hero carousel, product photo galleries and the standard enquiry form.
  4. Gaps in the reference docs: no Dojo Go Max specs (spec file is empty — its photos are Dojo Go), no address (map off), no testimonials, no photo of Tausif, no legal text. Dojo Pocket specs are taken from the supplied PDF.
  5. Refer a Friend has no dedicated section in the app, so it becomes hero slide 2 + a News & Events post.
